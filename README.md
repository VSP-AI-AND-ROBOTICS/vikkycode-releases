# Vikky Code

An AI coding agent for your terminal, running on your Vikky Platform key.
Part of [Vikky Verse](https://vikky.vspaiandrobotics.com) by VSP AI & Robotics.

This repository hosts release binaries and installers only.

## Install

macOS and Linux:

```sh
curl -fsSL https://github.com/VSP-AI-AND-ROBOTICS/vikkycode-releases/releases/latest/download/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://github.com/VSP-AI-AND-ROBOTICS/vikkycode-releases/releases/latest/download/install.ps1 | iex
```

Then:

```sh
vikkycode login   # paste your Vikky Platform API key
vikkycode
```

Get a key at https://vikky.vspaiandrobotics.com/platform.
